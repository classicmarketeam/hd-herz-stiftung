# Local Web Fonts

Lora (normal, weights 400-700) and Source Sans 3 (normal and italic, weights
400-700) are hosted here as variable WOFF2 files. Latin and Latin Extended
subsets use the matching Unicode ranges in `../../styles.css`.

Downloaded on 2026-10-05 from the official Google Fonts CSS API (Lora v37,
Source Sans 3 v20). No Google Fonts connection is needed at page load.

- Lora: https://github.com/google/fonts/tree/main/ofl/lora
- Source Sans 3: https://github.com/google/fonts/tree/main/ofl/sourcesans3
- Licenses: `Lora-OFL.txt` and `SourceSans3-OFL.txt` (SIL Open Font License 1.1).
